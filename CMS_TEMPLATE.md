# Единый шаблон страницы услуги для Tilda CMS

## Обязательные поля записи

1. `service_slug` — адрес страницы латиницей.
2. `service_name` — название услуги.
3. `eyebrow` — короткая надпись над заголовком.
4. `hero_title` — заголовок H1.
5. `hero_lead` — основной вводный текст.
6. `hero_note_1` и `hero_note_2` — два коротких тезиса.
7. `hero_image` и `hero_image_alt` — изображение и содержательное описание.
8. `primary_cta_label` и `primary_cta_link` — основная кнопка.
9. `seo_title` и `seo_description` — метаданные страницы.

## Повторяемые блоки

### Решения

- `solutions_title`
- `solutions_intro`
- карточки: `title`, `description`, `image`, `image_alt`, `sort_order`

### Задачи и объекты

- `tasks_title`
- пункты: `title`, `description`, `sort_order`

### Как строится работа

- этапы: `step_number`, `title`, `description`
- в текущем шаблоне предусмотрено пять этапов

### Ценность для заказчика

- `value_title`
- карточки: `title`, `description`, `sort_order`

## Необязательные блоки

### Показатели

- переключатель `show_stats`
- элементы: `value`, `caption`, `source_note`

### Кейсы

- переключатель `show_cases`
- элементы: `case_title`, `case_description`, `metrics`, `image`, `link`

### FAQ

- переключатель `show_faq`
- элементы: `question`, `answer`

## Финальный блок

- `cta_title`
- `cta_text`
- форма: имя, компания, телефон, электронная почта, направление и описание задачи
- ссылка на политику обработки персональных данных обязательна перед публикацией

## Порядок блоков

Первый экран → решения → задачи и объекты → процесс → ценность → показатели → кейсы → форма обращения.

Показатели и кейсы отключаются, если нет подтвержденного контента. Порядок основных блоков остается одинаковым для всех услуг.
