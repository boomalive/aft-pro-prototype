# Рабочий процесс AFT PRO

- После выполнения запрошенных правок и необходимых проверок сразу создавать коммит с относящимися к задаче файлами и отправлять изменения в `origin/main`. Пользователь заранее разрешил этот рабочий процесс; повторное подтверждение не требуется.
- После отправки проверять результат публикации GitHub Pages и давать в итоговом ответе прямую ссылку на сайт, а при изменении конкретной страницы — также ссылку на нее. Ссылка на коммит может дополнять ссылку для просмотра.
- Если отправка или публикация заблокирована либо еще выполняется, сообщать фактический статус.
