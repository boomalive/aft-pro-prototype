# Кольцо: настоящая 3D-модель для браузера, v1

## Открыть в браузере

Готовая страница: https://boomalive.github.io/aft-pro-prototype/ring-webgl-v1/

Для локального просмотра запусти HTTP-сервер в этой папке и открой `index.html`. Например: `python3 -m http.server 8000`.

Модель сама делает оборот за 16 секунд. Потяни мышью или пальцем для осмотра; колёсико или два пальца приближают. Есть пауза и возврат к исходному ракурсу. После ручного вращения автовращение возобновляется через 2,5 секунды, если оно было включено. При системной настройке уменьшения движения оно изначально выключено.

## Разместить на сайте

Для публикации используй `index.html`, `viewer.js`, `ring-web-v1.glb` и папку `draco/`. Загрузи их вместе, сохрани структуру папок. Эта версия работает через HTTP/HTTPS, модель загружается отдельным файлом и может кэшироваться. CDN и сторонние сервисы не используются.

Для вставки страницы с просмотрщиком в HTML-блок сайта можно использовать iframe:

```html
<iframe src="https://boomalive.github.io/aft-pro-prototype/ring-webgl-v1/"
        title="Кольцо — просмотр 3D"
        style="display:block;width:100%;height:760px;border:0"
        loading="lazy"></iframe>
```

Замени адрес на адрес размещённой страницы. Высоту можно адаптировать под макет. Для просмотра локальной копии нужен HTTP-сервер: браузер ограничивает чтение соседних файлов при открытии двойным кликом.

## Что передать разработчику

Весь этот пакет. Файл `ring-web-v1.glb` содержит исходную геометрию кольца и 37 камней, материалы, гравировку и встроенные текстуры металла 2048×2048. Внешние картинки не нужны. GLB весит около 2,34 МБ и использует стандартное сжатие `KHR_draco_mesh_compression`. Просмотрщик уже содержит нужный декодер.

В GLB находятся стандартные PBR-материалы, прозрачность камней, IOR 2,42 и параметры объёма. Выразительные внутренние отражения бриллиантов дополнительно рассчитывает шейдер в `viewer.js`. Чтобы сохранить этот вид на сайте, нужен этот просмотрщик или перенос его освещения и шейдера. В другом просмотрщике один GLB может выглядеть иначе.

Освещение создаётся программно: светлая студия, плавные световые панели, узкие тёмные отражения, отдельное окружение для камней. Контактное затемнение под камнями сохранено в цветах вершин металла. Плоскость пола, световые панели и камеры не входят в GLB.

В `developer-source/` лежат исходники просмотра на TypeScript. Зависимости: `three@0.178.0`, `three-mesh-bvh@0.9.15`. `viewer.js` уже собран и не требует сборки для размещения.

## Качество и проверка

Геометрия содержит 160 982 треугольника. Draco: позиции 16 бит, нормали 14, UV 16, цвета 12, прочие атрибуты 16. Число треугольников и разрешение текстур сохранены; сжатие координат вносит небольшую погрешность.

При вращении на медленных устройствах просмотрщик снижает разрешение отрисовки и число внутренних отражений. При паузе возвращает максимальное качество. При скрытой вкладке или вне экрана отрисовка останавливается; неподвижная модель перерисовывается только при изменениях.

Проверены открытие одного HTML без интернета, загрузка отдельного GLB через локальный HTTP, автовращение, пауза, возврат к ракурсу, мышь, эмуляция касаний и мобильного экрана в Chrome на Apple M3. Реальные мобильные устройства и Safari отдельно не проверялись. Ошибок JavaScript и шейдеров в этих проверках не было.

Валидатор Khronos не обнаружил ошибок или предупреждений в исходной несжатой модели и структуре сжатого GLB. Загрузка и отображение Draco-потока проверены в браузере.
