# AFT PRO clickable prototype

Статический многостраничный прототип, готовый для демонстрации клиенту и последующей публикации на GitHub Pages.

## Страницы

- `index.html` — главная;
- `design-test.html` — отдельная тестовая главная по «финальному концепту» Figma; остальные страницы сохраняют структурный прототип;
- `services.html` — директория услуг;
- `service-logistics.html` — логистика;
- `service-engineering.html` — инжиниринг;
- `service-robotics.html` — роботизация;
- `service-consulting.html` — консалтинг;
- `service-service.html` — сервис;
- `contacts.html` — контакты.

## Локальный просмотр

Откройте папку через локальный веб-сервер. Все ссылки относительные и будут работать на GitHub Pages без сборки.

## Тестовая главная с дизайном

[Открыть отдельную тестовую страницу](https://boomalive.github.io/aft-pro-prototype/design-test.html).

Первый экран и шапка перенесены из [«финального концепта» Figma](https://www.figma.com/design/Qwtqc2k9RXY8esVGhBSwVm/AFT-PRO?node-id=676-379). На ширине 1200 px используется исходная композиция 1200 × 640; на других широких экранах она масштабируется целиком. Мобильная композиция адаптирована для читаемости. Исходное изображение, логотип и графика хранятся в `assets/concept`; временных ссылок Figma во время просмотра нет. Шрифты Inter / Inter Tight загружаются локально, лицензии находятся в `assets/concept/fonts`.

Нижние секции используют контент прототипа и композиционные приемы [spacult.ru](https://spacult.ru/): типографическую иерархию, асимметричные сетки и переключаемые информационные блоки. Цель и миссия вынесены во второй блок. Фоновая фотография используется только в первом экране; новые изображения и карта остаются заглушками.

Координатный маркер плавно перемещается по случайной траектории, а цифры меняются независимо. Движение приостанавливается за пределами экрана, в скрытой вкладке и при настройке уменьшения движения. Формы сохраняют демонстрационное поведение прототипа.

## Важное

Формы демонстрационные: они показывают сообщение об успешной отправке, но не передают данные. Перед публикацией нужно подключить обработчик форм и политику обработки персональных данных.

Синие круглые маркеры содержат редакторские комментарии. Они появляются при наведении или фокусе и отмечают только те данные, которые нужно подтвердить или заменить перед публикацией.

Структура полей для переноса в Tilda описана в `CMS_TEMPLATE.md`. Перечень новых и адаптированных формулировок находится в `CONTENT_CHANGES.md`.
