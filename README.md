# AFT PRO clickable prototype

Статический многостраничный прототип, готовый для демонстрации клиенту и последующей публикации на GitHub Pages.

## Страницы

- `index.html` — главная;
- `design-test.html` — отдельная тестовая главная по «финальному концепту» Figma; остальные страницы сохраняют структурный прототип;
- `services.html` — директория услуг;
- `service-logistics.html` — логистика;
- `service-engineering.html` — инжиниринг;
- `service-robotics.html` — роботизация;
- `service-consulting.html` — консалтинг;
- `service-service.html` — сервис;
- `contacts.html` — контакты.

## Локальный просмотр

Откройте папку через локальный веб-сервер. Все ссылки относительные и будут работать на GitHub Pages без сборки.

## Тестовая главная с дизайном

[Открыть отдельную тестовую страницу](https://boomalive.github.io/aft-pro-prototype/design-test.html).

Первый экран и шапка перенесены из [«финального концепта» Figma](https://www.figma.com/design/Qwtqc2k9RXY8esVGhBSwVm/AFT-PRO?node-id=676-379). Первый экран сохраняет исходную композицию 1200 × 640 в десктопных макетах; для планшета и телефона предусмотрена отдельная композиция. Вся страница масштабируется по четырём фиксированным макетам, как Zero Block в Tilda. Исходное изображение, логотип и графика хранятся в `assets/concept`; временных ссылок Figma во время просмотра нет. Шрифты Inter / Inter Tight загружаются локально, лицензии находятся в `assets/concept/fonts`.

Нижние секции используют контент прототипа и композиционные приемы [spacult.ru](https://spacult.ru/): типографическую иерархию, асимметричные сетки и переключаемые информационные блоки. Цель и миссия вынесены во второй блок. В направлениях услуг используются фотографии из архива пользователя, а у каждого преимущества — своя фоновая фотография и иконка. Медиа оптимизированы в WebP, для фотографий есть версии шириной 640 и 1280 px; источники описаны в `assets/concept/media/README.md`. Для отраслей созданы четыре тематических изображения, сохранены адаптивные WebP 480/960 px. Карта построена по геоданным Natural Earth и показывает центры четырёх городов без всплывающих окон. Кейсы представлены компактной горизонтальной лентой с цветными фотографиями с действующего сайта АФТ; управление находится под заголовком. Клиенты разделены на две встречные бесконечные строки: 8 логотипов из первого HTML-фрагмента пользователя и 12 из второго, с внешними ссылками на оптимизированные изображения Tilda CDN. Источники и внешние зависимости описаны в `assets/concept/clients/README.md`.

Цвета интерфейса соответствуют UI kit: `#003449`, `#43B6A5`, `#567988`, `#F4242B`, `#7AAABE`, белый. Светлый градиент идет от `#F8F9FA` к `#F1F3F6`. H1/H2 уменьшены примерно на 15% на десктопе и на 20–25% на мобильных экранах; значения размеров округляются до целых пикселей. Мобильные H3 — 24 px в услугах и преимуществах, 22 px в карточках кейсов и отраслей. В мобильных базовых макетах внешний отступ — 10 px, нумерация направлений услуг скрыта. Размеры шрифтов и отступов относятся к базовому макету и масштабируются вместе со всей страницей.

Координатный маркер плавно перемещается по случайной траектории, а цифры меняются независимо. Движение приостанавливается за пределами экрана, в скрытой вкладке и при настройке уменьшения движения. В форме подписи перемещаются внутрь поля при фокусе и остаются сверху после заполнения. Согласие на обработку персональных данных запрашивается отдельным обязательным чекбоксом со ссылкой на действующую политику АФТ. Формы сохраняют демонстрационное поведение прототипа.

## Брейкпоинты и автоскейл тестовой главной

| Ширина окна | Базовый макет | Боковые отступы в макете |
| --- | --- | --- |
| От 1440 px | 1440 px | 40 px |
| 1200–1439 px | 1200 px | 20 px |
| 640–1199 px | 640 px | 10 px |
| До 639 px | 320 px | 10 px |

Коэффициент масштаба — доступная ширина окна / ширина выбранного макета. Например, на 1920 px макет 1440 увеличивается в 1,333 раза, на 960 px макет 640 — в 1,5 раза, на 390 px макет 320 — в 1,21875 раза. Ниже 320 px макет 320 уменьшается.

`design-scale.js` задаёт макет и масштаб до первого отображения страницы. `.site-canvas` использует CSS `zoom`, поэтому вертикальная высота документа, якоря и клики учитывают масштаб без ручных пустых отступов. Container queries и единицы `cqw` рассчитывают сетки и размеры относительно базового макета; изменение ширины внутри одного диапазона меняет только масштаб. Мобильное меню переключается по выбранному макету, шаг прокрутки кейсов и скорость бегущих строк рассчитываются в его координатах. Первый экран дополнительно сохраняет исходный холст Figma внутри общего масштаба. Остальные страницы прототипа эту систему не используют.

## Важное

Формы демонстрационные: они показывают сообщение об успешной отправке, но не передают данные. Перед публикацией нужно подключить обработчик форм и политику обработки персональных данных.

Синие круглые маркеры содержат редакторские комментарии. Они появляются при наведении или фокусе и отмечают только те данные, которые нужно подтвердить или заменить перед публикацией.

Структура полей для переноса в Tilda описана в `CMS_TEMPLATE.md`. Перечень новых и адаптированных формулировок находится в `CONTENT_CHANGES.md`.
