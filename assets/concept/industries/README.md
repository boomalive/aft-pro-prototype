# Изображения отраслей

Четыре изображения созданы генератором по запросу пользователя для тестовой главной. Это иллюстрации отраслей, а не фотографии конкретных проектов АФТ. Надписи и логотипы в изображения не добавлялись. Белый угловой маркер отображается отдельно средствами CSS.

- `chemistry` — фасовка и паллетирование химической продукции.
- `fertilizers` — фасовка минеральных удобрений в биг-беги.
- `oil-gas` — транспортировка крупного промышленного реактора.
- `distribution` — автоматизированный распределительный центр.

Веб-версии: WebP 960 × 720 и 480 × 360 px. Общий вес всех восьми файлов — около 716 КБ. Браузер выбирает размер через `srcset`.
