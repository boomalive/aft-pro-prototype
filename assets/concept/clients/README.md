# Логотипы клиентов

На тестовой главной используются логотипы из двух HTML-фрагментов, переданных пользователем: 8 российских клиентов из первого фрагмента и 12 международных из второго. Порядок сохранён; повторы исходной ленты удалены перед созданием собственных копий для бесконечной прокрутки. Иконки стрелок из исходных фрагментов в перечень логотипов не включены.

По разрешению пользователя изображения загружаются по внешним ссылкам Tilda CDN. В присланном коде уже есть оптимизированные WebP 400 × 200 px; используются эти точные URL, без поиска других вариантов логотипов.

У трёх файлов нет названия компании в имени или атрибутах исходного HTML. Для них сохранены сами изображения и нейтральные alt-подписи; названия компаний не угадывались.
