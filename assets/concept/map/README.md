# Карта офисов

Статичный SVG построен по реальным геоданным Natural Earth, без генеративной графики и внешнего API во время просмотра.

Источник: https://github.com/nvkelso/natural-earth-vector/tree/master/geojson — слои `ne_50m_land`, `ne_50m_lakes`, `ne_50m_rivers_lake_centerlines`, `ne_50m_admin_0_boundary_lines_land`. Natural Earth — public domain: https://www.naturalearthdata.com/about/terms-of-use/.

Проекция Меркатора, окно 23–67° в.д., 51,5–63,5° с.ш. Отмечены только четыре города, без точных адресов офисов и всплывающих окон.

| Город | Широта | Долгота |
| --- | --- | --- |
| Усть-Луга | 59.66028 | 28.27694 |
| Москва | 55.754110 | 37.613577 |
| Нижний Новгород | 56.334953 | 43.998148 |
| Екатеринбург | 56.851976 | 60.598014 |

Координаты Москвы, Нижнего Новгорода и Екатеринбурга взяты из `ne_50m_populated_places`; координаты центра поселка Усть-Луга — из [географической карточки поселка](https://en.wikipedia.org/wiki/Ust-Luga). Города на схеме являются точками присутствия, а не адресами конкретных зданий.
