# Материалы страницы логистики

Источники PNG услуг и шести SVG-иконок — приложенный пользователем файл
«AFT PRO – грузоперевозки.html», сохранённая страница действующего сайта АФТ.
Исходные URL извлечены из `data-original`, а не из локальных путей Chrome.

- Услуги: запись `rec2194099571`, 14 изображений в порядке `logistics.solutions`.
  Мобильная запись `rec2641645101` дублирует те же материалы.
- Доверие: запись `rec2194185851`, `icon1_accent.svg`–`icon6_accent.svg`
  в порядке `logistics.values`.
- Полный перечень оригиналов: `sources.json`. Те же URL используются
  непосредственно в `service-logistics.js`, поэтому дополнительного запроса
  манифеста при открытии страницы нет.

Материалы подключены внешними ссылками к `static.tildacdn.com`, как логотипы
клиентов главной. HTTP-политика рабочей среды запрещает скачивание с этого
домена (CONNECT 403). Изображения не заменялись самодельными; для проверки
их загрузки нужен браузер с доступом к CDN. Локальные проверки отдельно
проверяют точное соответствие ссылок предоставленному HTML и доступность
всех локальных ресурсов. Полукруглые подставки и свечение реализованы CSS.

Три фона hero уже сохранены локально, с адаптивными вариантами 640/1280 px:

1. `../benefits/integrated-logistics.webp` — комплексная логистика;
2. `../benefits/complex-transport.webp` — перевозка тяжёлого оборудования;
3. `../media/intermodal-terminal.webp` — интермодальный терминал.

Источники фотографий описаны в `../benefits/README.md` и `../media/README.md`.
Кейсы используют общий с главной рендер `renderConceptCases()` и цветные
фотографии из `../cases/` без копирования компонента или его CSS.
