# Материалы страницы логистики

Источники — приложенные пользователем «AFT PRO – грузоперевозки.html» и
`photosweb2.zip`, сохранённые материалы действующего сайта АФТ.
Оригинальные URL извлечены из `data-original`, а не из локальных путей Chrome.

## Композиция услуг

`service-orbit.svg` — исходный `Frame124talke.svg` из архива: тонкий незамкнутый
эллипс с исчезающим верхним контуром. SVG используется целиком в квадратной
композиции. По центру находится изображение, справа внизу — белый круг с номером.
Цветное свечение удалено по следующей правке пользователя. На hover и
клавиатурном фокусе изображение уменьшается до 85% и смещается на 10% вниз. Разделительная линия над текстом отсутствует.

Файлы скопированы без изменения содержимого. Остальные PNG услуг в архиве имеют
размер 20 × 20 px: это миниатюры загрузки Tilda, они не подходят для карточек
и не увеличивались. Остальные 11 услуг сохраняют ссылки на полные оригиналы CDN.
Логотипы, фоновые фото и прочие материалы архива не добавлялись в эту страницу.

## Проверка происхождения

- Услуги: HTML-запись `rec2194099571`, 14 изображений в порядке `logistics.solutions`.
  Мобильная запись `rec2641645101` дублирует те же материалы.
- Доверие: запись `rec2194185851`, `icon1_accent.svg`–`icon6_accent.svg`
  в порядке `logistics.values`.
- `sources.json` сохраняет полный перечень оригинальных URL и соответствие локальных
  файлов архиву. Фактические пути для рендера перечислены в `service-logistics.js`.
- HTTP-политика среды запрещает скачивание с `static.tildacdn.com` (CONNECT 403).
  Изображения из архива и локальные SVG проверены в браузере; для оставшихся
  11 внешних PNG проверяется соответствие исходному HTML.

Три фона hero уже сохранены локально, с адаптивными вариантами 640/1280 px:

1. `../benefits/integrated-logistics.webp` — комплексная логистика;
2. `../benefits/complex-transport.webp` — перевозка тяжёлого оборудования;
3. `../media/intermodal-terminal.webp` — интермодальный терминал.

Источники фотографий описаны в `../benefits/README.md` и `../media/README.md`.
Кейсы используют общий с главной рендер `renderConceptCases()` и цветные
фотографии из `../cases/` без копирования компонента или его CSS.
