# Шрифты для сравнения

- Inter — существующие локальные файлы проекта в `assets/concept/fonts`, SIL Open Font License.
- Manrope — Google Fonts, https://github.com/google/fonts/tree/main/ofl/manrope, SIL Open Font License (`manrope-OFL.txt`).
- Onest — Google Fonts, https://github.com/google/fonts/tree/main/ofl/onest, SIL Open Font License (`onest-OFL.txt`).

Manrope и Onest сохранены как локальные переменные WOFF2 с латиницей, кириллицей и знаками, используемыми на сайте. Внешний сервис шрифтов при просмотре не требуется. На тестовой главной гарнитуры меняются компактным фиксированным переключателем. Размеры текста и прочие настройки при переключении сохраняются.
